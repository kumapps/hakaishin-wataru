# 決定記録

重要な決定を追跡する。現行仕様の正本は担当テーマの仕様書、現在の進捗は [ROADMAP.md](ROADMAP.md)、実施済み変更は [CHANGELOG.md](CHANGELOG.md) とする。既存仕様から決定事項を大量転記しない。

## 記録方式

1件ごとにID、決定日（Asia/Shanghai）、対象機能、決定内容、決定理由、関連仕様書、実装状態を記載する。状態は [DEVELOPMENT_RULES.md](DEVELOPMENT_RULES.md) の4区分を使い、確認方法・範囲とPR／コミットも追記する。変更・撤回時は旧記録を消さず後続決定へ参照を残す。提案は決定と区別する。

## DEC-001：GitHub開発管理方針 v1.0

- 決定日：2026-11-08（Asia/Shanghai）
- 対象機能：仕様・ソースの管理、開発と公開の手順
- 決定内容：GitHubを唯一の正本とし、最終決定権はユーザーに置く。ChatGPTは企画・仕様検討、Codexは技術調査・実装・テストを主に担当する。4区分の状態管理、安定版mainと作業ブランチ、原則PR確認後の統合、公開版の明示承認、公開時のバージョンとGitタグ管理を採用する。難易度・認識基準・保存互換性・プライバシー・第三者ライセンスを保護し、履歴書き換え・強制pushは禁止する。
- 決定理由：チャットでの提案・決定・実装・確認を混同せず、安全で再現可能な開発と公開を行うため。
- 関連仕様書：[DEVELOPMENT_RULES.md](DEVELOPMENT_RULES.md)、[MASTER.txt](MASTER.txt)、[AGENTS.md](../AGENTS.md)
- 実装状態：実装済み・未確認（管理文書を作業ブランチに反映。PRのユーザーレビュー・mainへの統合は未実施）。今回のユーザー指示で方針は確定済み。ゲーム機能の変更・公開版更新は対象外。
