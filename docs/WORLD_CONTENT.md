# 漢字ダンジョン — 世界観・収録内容・美術・音

文書版：1.2／仕様セット：1.6.2／更新日：2026-10-20（Asia/Shanghai）
本番の物語と今回の途中開始デモを区別する。v0.9.25へ採用見本の素材と新規合成音を導入。全背景・全方向動作・完成録音は別工程。

## 1. 作品と世界

- 題名：漢字ダンジョン ― 破壊神・航 ―。漢字を操る力＝字力。RPGを遊ぶ中で覚え、実用上6～7割の定着を目指す。
- 古代の字力文明が衰退し、戦争・文字喰い等を背景に漢字が失われている。敵国が字力を復活させようとしているという大枠を保持する。
- 本番冒頭は村、兄妹が森へ、字力で魔物を倒す兵士をわたるが目撃し、長老から漢字と字力を学ぶ。動機は兵士への憧れ・興味。冒頭の詳しい台詞や全章構成は未制作。
- わたるは物理攻撃、すみれは魔法。通常UIはひらがな。航・菫等の名前の漢字を常時学習対象にせず、真名等のイベント扱いは将来の構想。
- 今回は物語途中のダンジョン攻略。外マップ・村の導入を初回デモへ追加しない。

## 2. 六字の社：8区画と進行

漢字を札と巻物に残した古い学びの遺跡。守り神が文字喰いに侵され、兄妹が札を集め暴走を鎮める。六字の社は採用した仮称で、ゲーム全体の正式名称とは別。

| 区画 | 取得・進行 | 代表字／敵・役割 |
|---|---|---|
| 入口 | 無属性5字を石碑から登録、初戦案内後同じ敵との通常戦闘 | 打／石の番人 |
| 根の広間 | 敵を突破し土5字の札、火薬庫へ | 根／火弱点の植物敵、追跡型1体 |
| 火薬庫 | 火5字と火薬の秘伝、字力結び、最初だけ火薬使用案内、岩を壊して奥へ | 薬／火弱点、火薬が役立つ |
| 風の回廊 | 風5字、旗と風が穏やかになり水路へ。難しいタイミング操作なし | 速 |
| 水路の間 | 水5字・氷流の秘伝、水の文字喰いと接触戦闘、水門の近道 | 氷／2体追跡、文字喰いは一方 |
| 封印の間 | 霊5字・守り神の記録、祭壇と寄り道への分岐 | 守／ここまでで180字 |
| ボス祭壇 | 炎の守り神を鎮め、社に光が戻る | 水弱点、最大600 |
| 隠し書庫 | 任意の強敵に勝利後、奥の巻物から死神の秘伝 | 火弱点、最大900。本筋に必須でない |

- 主経路：入口→根→火薬庫→風→水路→封印→祭壇。近道：水路↔根、入口↔根。書庫は封印から分岐。
- 書庫は封印の間の南西の壁の切れ目から、分岐・曲がり角・短い行き止まり2か所の裏通路を探索。通路は2タイル以上。正解矢印・追加魔法ヒントなし。
- 強敵の石板は裏通路の奥。実際に調べてから道しるべへ記録。書庫内レバーで旧入口を開き、封印の間へ戻る近道。外から先に開けない。
- ボス前に未習得・未マスター字があっても入場禁止にしない。氷流や書きが攻略に役立つ難易度。全30字マスター・寄り道制覇はクリア必須でない。
- ボス後は追加札・実際に結んだ魔法・マスター数を簡潔にまとめ、入口へ戻る／探索を続ける。封印を自動解除せず、後回しの解除・寄り道・魔法作成を続けられる。
- 物語の台詞案・各発見文の原文は分割前v1.5.21等に保存。秘伝の答えを会話で直接教える旧文面はMAGIC_SEALS.mdの謎文方針を優先。

## 4. 問題データと固定初戦

- 初期150字を30字ずつ5まとまりでユーザー確認し、全600問の内容を採用。追加30字120問と合わせ180字720問。文字・学年・属性のリストと初期漢字定着度3は維持する。
- 正本データ：kanji_questions_initial150_proposal_v0_1.json、initial150_tutorial_magic_proposal_v0_1.md。既存名称は維持し、状態は採用済み・内容版1.0へ更新する。初期魔法・チュートリアルはtutorial_magic_proposal_v0_1.json。
- 書きは漢字部分1文字で送り仮名を表示。読み・意味・英語は4択で正解1つ、表示順は実行時ランダム。代表的な語義を扱い、別の正しい読み・英訳・重なる意味をひっかけ誤答にしない。コマンドの書き2・読み意味英語各1の5問抽選は変更なし。
- 地は「じめん」の「じ」、日は太陽の「ひ」、気は気分の「き」。毛hairは人の毛、麦wheatは小麦、足footは靴を履く部分、心mindは感じ考える働きという文脈へ整える。
- 兄弟brother・姉妹sister・村里village・中内insideの共通訳を認める。林森・石岩等の重なる説明を競合誤答にしない。四し・七しち・九く、家home、大小large/little等の正しい関連語も誤答にしない。
- 上下は方向up/down、高は山の高さhigh、前後は位置front/back、春は季節spring。数の意味問題は漢数字が示す算用数字を選ぶ形式にする。
- 聞は「聞こえる」hear、知は「知っている」know。玉gemは宝石、金goldは金属、合matchは色の一致の文脈を添える。思考・言話・声音の意味の重なりも誤答設計で避ける。
- 固定初戦：航たたかう＝山書き→火読み→木意味→水英語→川書き／すみれまほう＝水玉2字全部なぞり／航へ敵通常攻撃10を1回／航漢字の書＝川書き→水読み→山意味→木英語→火書き。
- 案内中は時間無制限、同じ内容で再挑戦、5問全正解不要。実際に攻撃ダメージ・魔法発動・字力減少・回復が確認できたら次へ。初期字は定着度3部分なぞり、水玉は定着度1全部なぞり。案内中は敵の自由な反復攻撃・全員字力切れ・早期撃破を防ぎ、その後同じ敵の短い通常戦闘へ移る。
- 初期4魔法は定着度1・連続正解数0と確定。字力結びで新規登録する魔法は初回成功を含む連続正解数1。既定の魔法7種・名前・威力・書き順各字＋0.1倍・基本属性条件は変更しない。

問題・素材・AI対応は別。180字720問の内容採用は認識180字完成を意味しない。各問題の原文・選択肢は採用データと配布ZIP分割データを参照し、整理のために再生成しない。
追加15字×2群の問題採用記録は旧v1.5.25～26、初期150字の採用は旧v1.5.31。単体書きの送り仮名を固定表示し、該当1字を回答させる。

## 5. 採用美術の方向性

- デザインの軸は「彩色された和風の冒険絵巻に、漢字の力が息づいている」。架空の和風幻想世界として、字力・失われた漢字文明という既存設定と見た目をつなげる。
- 参考作品は『大神』と『朧村正怪奇譚』。前者の温かさ・筆の味・描くことと力のつながり、後者の豊かな彩色・衣装や風景の描写・人物の構えと剣戟の格好よさを、同じ重さで参考にする。
- 太さが変わる墨の輪郭と、手描きの豊かな彩色・陰影を組み合わせる。全体を墨絵だけにせず、人物・衣装・建築・自然の色と質感を持たせる。
- 武将への興味を、衣装・軽い装甲・旗印・構えの力強さに取り入れる。実在の戦国時代の甲冑・刀をそのまま再現する方向には固定しない。
- 親しみやすい兄妹が、美しく少し妖しい遺跡を冒険する雰囲気とする。子ども向けでも、人物や戦いの格好よさを中心に置く。
- キャラクター・敵・背景・UIを同じ美術方針で統一する。既存作品のキャラクターや紋章の直接流用ではなく、オリジナルの造形とする。

## 5.1. キャラクター動作素材（2026-10-20確定）

- GPTの画像生成は立ち絵・外見の制作に使い、歩行・ダッシュの全身連続画像はLudo.aiで生成する。コマの切り出し、GIF化、再生速度とループ調整、ゲーム上の確認は既存画像を加工して行う。

## 背景・漢字・演出
- 和風遺跡の基本素材は、苔むした石垣・石床・木柱・木組み・瓦屋根・格子・灯籠・古い旗や巻物。水路、木の根、落ち葉などで区画の違いを表現する。
- 漢字は石碑・封印・武器・古代装置など、字力と関係する場所に使う。背景の装飾に加え、世界の力として存在することを伝える。
- 未登録漢字の通常UI表示は従来のひらがな方針を維持する。発見対象の石碑・見本に漢字を描くことと、知識獲得済みとして登録することを混同しない。
- 魔法は、漢字や筆画が短く浮かぶ→人物や道具に力が宿る→炎・水流などの効果につながる表現を基準とする。
- 物理攻撃は、構え・踏み込み・刃の軌跡・被弾反応で爽快感を出す。演出のために新しい長い待ち時間を加えない。

## 6. 魔法・戦闘の完成演出

- すみれはその場で構える。投射・対象位置の効果など魔法ごとに変え、敵の位置へ炎・水・氷等の命中効果を付ける。敵の魔法も敵がその場で構え、狙った味方へ属性に合う効果を出す。
| 魔法 | 採用する演出 |
| --- | --- |
| 火花 | 火の玉が飛び、命中した敵に短い炎。 |
| 火の矢 | 火の矢が飛び、命中した敵に短い炎。 |
| 水玉 | 水の玉が飛び、命中時に水しぶき。 |
| 水の矢 | 水の矢が飛び、命中時に水しぶき。 |
| 火薬 | 敵の位置で小さな爆発。 |
| 氷流 | 敵の足元から氷が走り、氷柱が立つ。 |
| 死神 | 敵の背後に一瞬だけ影が現れ、鎌の軌跡が走る。 |
- 魔法の命中・到達時に既定の最終ダメージを適用し、その場に短い効果を出して消す。次の対象選択や技を長く隠さない。死神は通常のダメージ魔法のまま、即死能力を追加しない。
- 魔法名・威力・属性・対象数・学習判定は既定から変更しない。各演出時間は内部パラメータで調整する。



- 物理は踏み込み・刃の軌跡・被弾反応。敵は噛みつき・体当たり等。長い待ち時間や入力欄を隠す大演出を増やさない。
- 回復は書を開き淡い光と漢字の粒、文字喰いは吸い込み、解除は帰還。実値の適用時刻は演出で遅延させない。
- 字力切れは膝をつき薄く、敵撃破は墨の粒。仮コードでの点滅等と、完成素材の実装を区別する。

## 7. 音：方向性確定・今回デモから導入

- BGMは探索・通常戦闘・強敵戦の3種類＋短い勝利音。ボスと影は強敵曲を共用。探索と戦闘は短くクロスフェード。敗北専用曲は追加せず静かにフェードし、保存からの探索再開へ接続。
- 探索は静かな和風・神秘性、戦闘は回答の邪魔にならない緊張感、強敵は迫力。音量と消音を通常設定へ、非表示停止と再開に接続。
- 物理の振り／命中、魔法の発動／属性命中、吸い込み、澄んだ解除、書と柔らかい回復の効果音。
- 正解は軽く短く、不正解は控えめ。書き順・5コンボを短い追加音で強調。MISS専用ブザーはなし。
- 選択・決定・戻るは短い操作音、押せないボタンは無音。手書き・スティック中に音を鳴らさない。操作音は効果音音量と共通管理。
- 今回は非商用、AI音楽はSuno無料プランを候補とし有料加入を必須にしない。素材選定時に最新の取得・利用・再配布条件を確認する。条件や音源選定が完了したとは扱わない。
