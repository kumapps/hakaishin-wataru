# 漢字ダンジョン — 探索・遭遇・復活・保存

文書版：1.5／仕様セット：1.6.0／更新日：2026-10-23（Asia/Shanghai）
物語・札配置はWORLD_CONTENT.md、画面共通はUI_COMMON.md、戦闘はBATTLE_DEMO.txt。

## 1. 探索移動と停止

- 円形スティックの方向へ連続自由移動。マス中央へ固定せず、斜めも同速度。壁・柱・水路の輪郭で止まり、壁に沿って滑る。角抜け・通れない水路の横断を防ぐ。
- すみれはわたるの通った経路を少し遅れて追い、障害物を横切らない。柱等の後ろで人物が隠れる奥行き、滑らかなカメラ追従。通常探索のズームなし。
- 採用初期値は歩き3.0タイル/秒、走り6.4、連続移動1.0秒後、0.2秒で加速。実際に動いた時間で判定し、壁押し中は加算しない。方向変更だけでは走りを解除しない。
- 指を離す・入力取消・会話・メニュー・画面切替・戦闘開始では入力を解除。再開は歩きから。追従も歩き／走りを合わせる。値はデバッグ調整可能。
- 区画はイベント・保存・復活の内部管理として残すが、同一フロアの区画境界で暗転・読み込み待ちを挟まない。別フロアには別表示区画を許容。
- 会話・手帳・漢字の書・入手中は移動と探索敵を停止。止まったスティック・ボタンを薄くし入力不可。短い通常通知は移動を止めない。

### 動作画像と長押しダッシュ（2026-10-20）
- 方向入力で歩行し、長押し／連続移動でダッシュへ移る方式を維持。方向キーを使う確認試作でもこの方式を確認した。タッチの円形スティックを廃止する変更ではない。
- 動作画像の制作方法、採用コマ、切替姿勢と補間要件はWORLD_CONTENT.md 5.1を正本とする。画像の再生間隔とマップ上の移動速度は別に管理する。
- 確認試作では長押し約0.55秒で切替。ユーザー了承は歩行7→ダッシュ3の切替姿勢を含む確認上のタイミング。本編の連続移動1.0秒・加速0.2秒を0.55秒へ置換する明示決定はないため、既定値を維持し本体接続時に調整する。
- 補間を入れた実際の接続は未確認。本体v0.9.25へ今回の素材を実装済みとは扱わない。

## 2. 調べる・冒険の手帳

- 調査対象の近くで「調べる」。対象タップも対応し、対象の強調・操作案内は短くする。歩くだけで重要な長文を強制表示しない。
- 会話はマップを見せたまま下部メッセージ枠に話者名・短文。タップで全文→次へ→閉じるの順。選択肢は同枠で分かるようにする。
- v0.9.31は総合入口「漢字の書」から「冒険の手帳」を開く。探索トップに手帳の独立ボタンを置かない。旧「道しるべ」の情報を統合した名称と本文を維持する。
- 一覧は既存の見出し・済表示を活かし、入手したタスクと、旧道しるべにあった石碑・石板等の背景記録を新しい順にまとめる。今いるダンジョンの既知情報だけを表示し、未入手ヒント・新しい正解説明を加えない。
- 手帳の本文領域を上半分の記録一覧・下半分の選択内容へ分割し、同一画面に常時表示。項目全体のタップで下半分の見出し・本文・済を更新する。初期選択は最新の記録。選択を見た目で示し、一覧の位置を維持する。一覧と本文はそれぞれ独立してスクロール。空なら上側に「まだ、記録はない」。
- 詳細への画面遷移・「一覧に戻る」を廃止。右下固定の「漢字の書に戻る」で総合入口へ戻る。戻る不具合の報告を受け、戻り先を直接結び、タッチによる開閉反復を検証する。
- 行動完了の見出しに「済」。魔法登録・岩破壊・ボス撃破等の実状態で判定し、詳細にも済を表示。背景説明に済を付けず、完了後も本文を読み返せる。閲覧だけで解決・魔法登録・学習履歴を書き換えない。
- 重複記録を防ぎ、従来のread・完了フラグ・保存形式を継続利用する。手帳閲覧中は移動と探索敵を停止し、非表示からの再開は共通規則に従う。
- 場所別管理・未完了／すべて・並べ替え・既読管理・大量時の検索要否などは後続TODO。今回の一覧・詳細追加から先取りしない。

## 3. 敵グループと遭遇

- 敵は1グループ1～3体を探索中から表示。接触したグループの参加者を開始時に固定し、他グループを乱入させない。戦闘中は他グループ停止。
- 今回は全敵の開始条件を「わたるが生存敵へ接触」で統一。すみれだけの接触では始めない。接触距離基準1.35。
- 根の広間1体、水路の間2体は追跡型。その他は固定。発見→接触→戦闘の順で、発見しただけでは戦闘開始しない。
- 同時に複数グループへ接触した場合は最も近い対象、同距離はマップ設定順。勝利後の探索復帰に初期仮値1秒の遭遇猶予。
- 猶予は探索中だけ進める。会話・メニュー・非表示中には消費しない。新しい常設猶予メニューは作らない。
- 移動方式と戦闘開始条件を分離して敵別に設定する。本番の視界開始型・範囲進入型の具体イベントは別途配置時に設計。

## 4. 追跡・帰還

- 指定範囲・発見距離・視野・遮蔽を使う。発見時に短く「！」。壁越しに発見せず、水路・壁・柱を通らない経路で追う。
- 歩くわたるより少し遅い速度を上限にし、逃げられる。指定行動エリアから離れたら通行経路に沿って元位置へ帰還。帰還中は再発見して追い直さないが、接触すれば戦闘可能。
- グループの仲間も追い、重なりすぎない間隔を維持。橋を渡る前後差を許し、ワープ・障害物横断で揃えない。
- 現デモの共通仮値：発見3.2、視野360度、追跡2.2（歩きの80％上限）、帰還2.6、範囲倍率1、仲間間隔0.62、発見表示0.7秒。
- 根の基準行動距離はv0.9.21で3.5→8へ拡大。根の部屋範囲内に制限。水路は12。速度・発見距離は拡大に伴って変えない。
- 追跡の位置は実際の戦闘開始位置に渡し、元位置へ瞬間移動させない。探索中断では敵・追跡・猶予を止める。
- 行動範囲・発見等の設定は探索の敵デバッグで調整・保存。範囲倍率変更時は元位置へ戻して再開。調整値を本番難易度の確定値へ自動転用しない。
- 追跡途中の位置・経路・猶予は進行セーブへ保存しない。読込時は生存敵が元位置へ戻る。撃破・復活・攻略は引き継ぐ。

## 5. 通常敵の復活：本番にも使う共通規則

- 表示名とは別の復活判定区画と、区画間の接続距離をマップデータに設定する。
- 倒した通常敵の所属区画から接続距離2以上離れた区画へ探索で移った時に復活。移動回数を累積しない。隣接往復だけでは復活しない。再戦後も同じ規則。
- 分岐・近道の距離は明示設定し、通路を開けたことから自動短縮しない。細い通路は近くの区画に含める。
- 復活は元の配置・字力全回復。到着先と同区画は距離0なのでその移動では復活しない。読込だけでは判定しない。
- 初回撃破の恒久記録と、現在の撃破状態を分ける。門・札・秘伝・魔法・仕掛け・学習を戻さず、初回会話や報酬を反復しない。
- ボス・影・イベント敵は自動復活対象外にできる。今回ボスと影は自動復活なし、通常5遭遇は共通規則。旧入口1回限りの特例は廃止。

六字の社：主経路は入口→根→火薬庫→風→水路→封印→祭壇、各距離1。入口↔根の近道は1、根↔水路は3。水路の帰り道は水路、裏通路・書庫は封印と同じ判定区画。書庫往復だけでは復活しない。

## 6. 仕掛けとイベント魔法

- v0.9.29から「仕掛けを調べる→メッセージの『まほう』→魔法を選ぶ→魔法名を書く→発動演出→仕掛けへの効果」の流れに統一する。v0.9.28の即時発動はユーザーの再評価により置換。探索メニューのまほう一覧は引き続き詳細・練習用で、自由な攻撃・回復を追加しない。
- 「まほう」を出す前提は仕掛けごとのデータで管理。必要魔法の登録、道しるべ／記録の既読、敵の恒久撃破などを組合せ可能。今回の岩は火薬登録、水門は氷流登録という既存条件を維持し、新しい既読・撃破条件を一律追加しない。未達時は状況文のみ。
- 条件を満たしたら共通の「まほう」ボタンを表示し、「火薬を使う」「氷流を使う」など正解を指定するボタンは出さない。登録済み魔法を共通の属性別2列一覧から選ぶ。正解だけを強調・先頭へ移動・自動選択しない。未登録は非表示、すみれ本人の基本属性不足・封印中は該当魔法を選べない。
- 選んだ魔法名を時間制限なしで書く。補助は魔法の定着度に従い全部／一部／なし、1画ガイドは既存基準を維持。固定「の」は入力・判定から除外。字形正解後は「完了」を挟まず発動演出へ。書き誤りは発動せず再試行・選び直し可能、処理エラーは同じ筆跡を保持して再回答。
- 書きが正しくても仕掛けに合わない魔法なら発動演出後「何も起きなかった。」と表示し、開通・道しるべの済状態を変えない。「まほう」から選び直せる。字形の学習記録と謎解きの選択正誤は分ける（LEARNING 2.2）。追加の字力消費・選択ミスのペナルティなし。
- 今回の岩は火薬、水門は氷流で解決。すみれの該当属性封印中は使えず、わたるだけの封印は妨げない。水門の近道が未開通でも本筋は進む。発動開始時・効果確定時に資格を確認。
- 会話・魔法選択・書き・発動演出中は探索と敵移動を止め、非表示／停止中は進めない。途中で戻る・選び直すだけでは未回答を誤答にせず、仕掛けを完了しない。回答済み学習記録は保持する。
- 正しい魔法の発動完了時に開通と道しるべを一度だけ保存。完成済みの仕掛けは再発動しない。取消・誤選択・誤字では開通フラグを付けず、再読込後も保存済みの状態を維持。保存失敗は重要な案内として表示する。

## 7. 保存・タイトル・中断

- 単一の進行セーブ。イベント確定・区画移動・戦闘直前の自動保存と、探索中の手動保存。位置・字力・本人別封印・漢字／魔法／秘伝・学習・撃破・恒久開通・説明済みを保存。
- 回答途中・戦闘演出途中・選択途中は保存しない。ブラウザ再読込は最後の保存から。戦闘の中間状態を復元しない。
- 勝利は封印を保持し有効最大まで現在回復後に結果を保存。敗北戦の状態は上書きせず「前回のセーブから」で丸ごと読込。保存時点の封印・学習を戻す。
- 敵への接触位置で敗北再開した場合は、一度離れるまで再遭遇を抑止。離れて再接触すれば戦える。
- ホーム画面・別アプリ・ロック等で非表示になったら全進行停止、入力解除。戻ったら「再開」操作で復帰し、経過時間を一括加算しない。状態保持の一時停止と、再読込による保存復元を区別。
- 常設のⅡボタン・新しい手動一時停止メニューは今回追加しない。
- タイトル「はじめから」は保存なしなら直接開始。保存あり／破損ならゲーム内で上書き確認。左「はじめる」・右「タイトルに戻る」。標準window.confirmに依存しない。
- 取消・Escapeで保存を変更せず通常タイトルへ。確定した時だけ新規開始・保存。タイトルを開き直すと確認を閉じた状態へ。確認用の途中開始は新しい検証状態で保存を上書きする操作と区別して説明する。
- 旧セーブを消して移行しない。追加状態を互換補完し、地形変更で無効な位置なら近くの床へ移す。schema2と既存キーを維持する。
- 通常敵の現在撃破defeatedと恒久clearedは別。旧データはdefeated・入口開通／旧復活フラグで補完し、読込時に現在の敵を勝手に復活させない。
