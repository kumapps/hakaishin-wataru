# 漢字ダンジョン — 学習・漢字の書・個別練習

文書版：1.7／仕様セット：1.6.0／更新日：2026-10-25（Asia/Shanghai）
適用：v0.9.29。探索の魔法入力と仕掛けの選択を分離。短い出題文、代表1字／スキップ同等、全180字、AIエラー再試行を維持。
実装・確認の最新状態は[ROADMAP.md](ROADMAP.md)、文字全体認識は[HANDWRITING.md](HANDWRITING.md)。

## 1. 登録と定着度

- 「知識を得て登録した」と「マスターした」を区別する。登録で使用可能になり、本来の最大字力を1字につき1増やす。定着度5がマスター。マスター到達による字力の追加加算はない。
- 重複登録では加算しない。定着度が下がっても登録・使用権・本来の最大字力は失わない。
- 新規漢字の登録で現在字力も+1。封印中でも同じ加算後、有効最大字力を上限にする。解除による差分回復とは別。
- 定着度は漢字単体・魔法名ごとに1～5。両者を別管理し、構成漢字の平均から魔法の定着度を作らない。
- 5回連続正解で定着度を1上げ連続数を0へ。誤答・時間切れでは1下げ、連続数を0へ。上限5・下限1。マスター時も連続正解の表示を残す。
- 書き・読み・意味・英語の正解は同じ漢字の連続数へ共通に数える。戦闘コンボの最大5問とは別の記録。
- 初期150字は定着度3、初期4魔法は定着度1・連続正解0。新しい漢字は定着度1。字力結びの初回成功は魔法の連続正解1として登録する。

## 2. 出題・正誤・記録

- 通常攻撃・戦闘中の漢字の書・探索中の封印解除は書き2・読み1・意味1・英語1の5問を基本にランダム順。固定チュートリアルは別。魔法は名前全体を書く1問。
- 登録済みの漢字から選ぶ。封印解除は選ばれた属性内に絞る。候補不足では同じ漢字の異なる形式を使い、同じ形式も不足時だけ重複可。問題数を減らさず、未登録字・別属性で埋めない。候補ゼロはデータ不備として別途扱う。
- 読み・意味・英語は4択・正解1つ、選択肢を実行時にシャッフル。別の正しい読みや英訳を誤答にしない。
- 通常補助は定着度1・2＝全部、3・4＝一部、5＝なし。任意練習の設定とは別。
- 漢字ごとに4種類別の累計と最近10問の正解数・母数・正答率を記録。魔法は書きのみ。未回答・中断を誤答として増やさない。回答済みの有効記録は中断後も保持する。
- 魔法は全体の正誤と構成字の各判定を分ける。水○・玉×なら、水○・玉×・魔法×。時間切れ／わからないは全体と構成全字を誤答。途中の個別判定を二重記録しない。固定「の」は除外。
- 種類不明の旧記録は種類を推測せず、旧合計・最近・定着度を保持。種類別は新回答から加算する。
- 苦手度＝最近10問の誤答率×0.7＋累積誤答率×0.3。苦手抽選の重み＝1＋苦手度×2。履歴なしは通常重み1、未学習を誤答にしない。得意な字も候補に残す。
- 漢字の書の「苦手」は履歴があり苦手度>0の字。敵が文字喰いで選ぶ属性の重みとは別。
- 「わからない」・別字認識・判別不能／保留・構造不一致は現問題の誤答として既定の記録へ接続する。2026-10-25決定のたたかう／戦闘中の漢字の書の「わからない」だけは次問へ継続（2.3）。その他の連続出題終了条件は維持する。モデル取得／実行等の処理エラーは誤答にせず、同じ問題・筆跡・成功数・残り時間を保持して再回答できる。処理エラーで学習記録は増やさない。

### 2.1 出題文・練習文（v0.9.27）

- 書きは文脈と「答える部分」だけを残す。「『』の部分を漢字1文字で書け」「〜を漢字で書け」などの定型指示を毎問付けない。例：`「にほんご」の「ご」`、`ボールを「う」つ`。
- 同音字の区別に必要な意味・文脈は残す。例：`「み」につける服（からだのこと）`、`火をつけて使う「すみ」（木から作る）`。答える部分の「」と送り仮名は維持する。
- 選択問題は`「火」の読みは？`／`「火」の意味は？`／`「火」の英語は？`、数は`「一」はいくつ？`とする。
- 魔法の入力は`「みずたま」`など読みだけ。個別練習・札の初回なぞり・字力結びも対象の字／読みだけを表示し、「なぞって書こう」を繰り返さない。
- 全画ガイド終了時の「回答を押そう」は削除し、既存の回答ボタン強調を使う。再試行の文は「もう一度」へ短縮。書き順成功表示は「書き順○」。
- 問題ID・解答・選択肢・補助量・出題数・時間・AI判定・記録規則は維持。文面の短縮によって問題の答えを提示したり、判定を変更したりしない。

### 2.2 探索の仕掛けで書く魔法（v0.9.29）

- 選んだ魔法を正しく書けたかと、仕掛けに合う魔法を選んだかを分ける。別の魔法を正しく書いた場合も書きは正解、仕掛けへの効果はなし。「何も起きなかった」を漢字の誤答として記録しない。
- 魔法全体と各構成字の学習記録は既存の魔法入力と同じく有効回答ごとに一度だけ確定。書き誤りは通常の誤答、処理エラー・未回答での選び直し・中断は追加記録なし。字力消費や別の謎解きペナルティを作らない。
- 時間制限なし。魔法の定着度1・2＝全部、3・4＝一部、5＝なしを使い、任意練習の設定は流用しない。字形正解から短い表示を経て自動で発動演出へ進む。初回字力結び・任意練習・戦闘の既存フローは維持する。

### 2.3 たたかう・戦闘中の漢字の書のパスと途中発動（v0.9.36実装）

- 「わからない」は現在の1問だけをパスし、既存どおりその問題は誤答記録・定着度／学習連続数の更新対象とする。次問へ進み、戦闘の既得正解数は保持する。学習の連続正解と戦闘の正解数を混同しない。補充問題なし、5問中1問をパスした場合の最大成功数は4。
- 「攻撃する」「回復する」は出題を終了し、そこまでの正解数で各行動へ進む。残りは未回答で、現在の書きかけを含め誤答・時間切れとして記録しない。回答済みの記録は保持し、途中発動自体で学習記録を増やさない。
- 名称は「攻撃する」「回復する」で承認。「ここで攻撃」「ここで回復」は不採用。最大5問の構成・正解と書き順の判定・威力／回復式は維持する。対象は戦闘中の2コマンド。魔法の1問・探索の封印解除・任意練習・初回なぞりは既存の規則を維持する。
- v0.9.36へ実装。途中発動は1正解以上で有効、正解結果表示中も使用可能。AI判定中・停止中・死亡後は確定しない。固定の初戦案内は既存の問題構成と終了条件を維持し、途中発動を追加しない。自動／ブラウザ検証済み、新方式のユーザー評価は今後。

## 3. 漢字図鑑の一覧と詳細

- v0.9.31で従来の漢字の書の漢字一覧を「漢字図鑑」（名称案）とし、総合入口「漢字の書」から開く。個別詳細からは図鑑、図鑑からは総合入口へ戻る。
- 一覧は漢字だけのマス。属性は背景・枠の色で区別し、マスへ属性名・定着度を併記しない。
- 見出し右に火・水・土・風・霊・無の凡例ボタン。同じ属性を再押下で解除、別属性で切替、切替時は一覧先頭へ。
- 絞り込み枠は学年・定着度・苦手。属性の重複した選択欄は置かない。検索・並べ替え・各条件を併用できる。
- 覚えた順は新しい順。学年順・属性順はグループ見出し。絞り込みの解除は検索・並べ順を保持する。
- 詳細／練習から戻ると一覧条件とスクロールを復元。新規開始・保存から再開では一覧の一時条件を初期化し、進行セーブへ追加しない。
- 検索キーボードでゲーム全体を縮めず、一覧の表示範囲だけ調整。検索中は凡例・条件枠・下部操作を隠し、検索確定でキーボードを閉じる。
- 詳細は大きな漢字と読み・意味・英語・学年・属性を中央、学習状況を下側、操作は最下部。小さな重複漢字は削除。
- 「練習する」から直接書き練習へ。総合入口「漢字の書」へ移した「字力結び」「封印を解く」の規則は[MAGIC_SEALS.md](MAGIC_SEALS.md)。

## 4. 個別練習は書きだけ

- 読み・意味・英語の個別練習・種類選択は再追加しない。戦闘問題・詳細情報・学習記録は4種類を維持。
- 下書き＝全部／一部／なし。書き順ガイド＝あり／なし。初回は全部＋あり。前回設定をブラウザに保持する。
- 下書きなしではガイド無効。下書きを戻すと以前のガイド設定を復元。ガイドだけを白紙上へ常時表示しない。
- 設定は操作エリアに重ね、入力欄を縮めない。設定を変更して適用した時だけ書きかけを消す。変更なしの適用・閉じるでは維持。
- 一部なぞりは約半分の画を丸ごとランダムに隠す。2画以上は1画以上残し1画以上隠す。1画の字は設定にかかわらず下書き・ガイドなし。
- 書き直し・誤答後の再試行では同じ画を隠す。正解後の「もう一度」で再抽選し、同じ組合せになる場合もある。
- ガイドありでは1画ごとに確認。違う画は薄く表示し短く「もう一度」、その画だけ消す。前の画は保持。隠した画にも順番が来た時だけ番号・矢印を表示する。
- 全画終了でガイドを消し回答を強調。最後の「回答」で文字全体を判定・記録。1画の再試行では学習記録を増やさない。
- 正解後は右側「もう一度」、左下「詳細に戻る」。途中終了は誤答にしない。結果で入力欄を縮めない。
- 札入手時は複数字でも代表1字だけ初回なぞり。開始前・なぞり中ともスキップ可能。全部＋ガイドあり固定（1画の字は例外）。正解後0.8秒で自動終了。スキップ／代表字正解のどちらも同じ時点でグループ全字を登録し、新規字は定着度1・連続0・学習履歴0、字力の増加も同じ。初回札なぞりを通常練習の正解・書き順報酬へ加算しない。任意の個別練習は従来どおり記録する。字力結び初回は成功が必要で、スキップによる魔法登録はない。全部＋ガイドあり、成功後「完了」。個別練習の自由設定を初回へ流用しない。

### 4.1 詳細からの全画面練習（v0.9.32）

- ユーザーが操作サンプルの構成を採用。漢字詳細・まほう詳細の「練習する」は、その詳細と同じ全画面の枠内で練習表示へ切り替える。探索マップと下側だけの入力へ戻さない。上側に問題、下側に手書き欄・書き直す・練習設定、最下部に左「詳細に戻る」・右「回答」を置く。
- 入力中は詳細の大きな漢字・魔法名・構成漢字・熟語例など答えを含む情報を非表示。漢字は既存の短い書き問題文、魔法は読みだけを上側へ表示する。問題の期待字・登録済み候補・判定・記録先は維持。
- 既存書き問題の説明中に期待字が含まれる父・母・家・国・学・金の6件は、個別練習だけ答えを含まない表現へ置換。戦闘等の問題データを変更せず、対象180字すべての練習文が期待字を含まないことを確認する。
- 有効な回答の判定後は正解・誤答のいずれでも上側へ正解の字／魔法名を表示し、右「もう一度」。筆跡は回答後も保持する。再挑戦で正解表示を消し入力を初期化。正解後は既定どおり一部下書きの隠す画を再抽選、誤答後は同じ隠し方で再試行。
- 「詳細に戻る」で元の対象の説明・学習記録を復元。詳細から図鑑／まほうへ戻った場合の既存の状態復元を維持。練習途中の未回答中断は誤答にしない。
- 下書き＝全部／一部／なし、書き順ガイド、既定値（全部＋あり）・前回設定の保存・1画例外は従来どおり。サンプルの表示や設定を理由に本体の既定値をなしへ変更しない。意図した入力欄の下書きと、上側の説明に正解が見え続ける問題を区別する。
- 字形判定は既存AIへ接続。有効回答を一度だけ通常記録し、処理エラーは筆跡・問題を保持し正解を表示せず再回答。停止・取消後の古い結果無効化を維持。画面サンプルの「採点なし」を本体仕様へ持ち込まない。
- 対象は詳細からの任意練習。札の初回なぞり・字力結び初回・仕掛け魔法・戦闘・封印解除の入力画面を一律全画面へ変更しない。時間制限・認識基準・ゲームの難易度を変更しない。
