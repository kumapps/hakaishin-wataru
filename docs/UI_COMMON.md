## 2. メニューと戻る

- 探索トップの旧「メニュー」ボタンを「漢字の書」に変更し、トップの冒険の手帳ボタンは撤去。漢字の書を機能の総合入口とする。
- 漢字の書は従来の下側操作エリア・2列配置を維持。項目は「漢字図鑑」「まほう」「字力結び」「封印を解く」「冒険の手帳」「セーブ」「設定」、右下に「探索に戻る」。従来の漢字一覧は名称案「漢字図鑑」で実装。独立した字力結び・封印解除を総合入口へ移し、図鑑内には重ねて置かない。
- セーブは漢字の書へ記録するイメージとし、成功表示を「漢字の書に記録した」とする。既存の保存形式・自動保存・失敗表示を維持。封印なしなら「封印を解く」は選択不可。
- 冒険の手帳は一覧と本文を同一画面の上下半分で表示。内容はEXPLORATION 2を正本とする。各機能から総合入口へは「漢字の書に戻る」。
- 漢字の書・各詳細・字力結び等の一覧は必要な全画面表示を使う。一覧だけスクロール、下部操作は固定。
- 書き練習を除き戻る機能は右下へ。魔法一覧・漢字の書・設定などでx/y・幅・高さを共通にし、内容量で上下しない。
- 2列の最後の右枠に戻るを置く。項目1つ＋戻るは同じ行。項目2つ＋戻るは次の行の右、左は空欄。一般に奇数項目は同じ最後の行、偶数は次行右。0項目は右だけ。
- 練習する＋一覧に戻るも同じ行。戻るを必ず一行下げる専用行ルールは撤回済み。
- 詳細からの漢字・魔法の任意練習はv0.9.32で全画面の枠を維持する練習表示へ。上側の答えを含む説明を問題に置換し、下側に入力欄。左「詳細に戻る」、右「回答／もう一度」を維持。詳細はLEARNING 4.1。その他の入力画面の配置へ一律適用しない。

- 新UIの味方は顔アイコンなし、名前＋コンパクトな固定幅の字力バー＋外周ATB。通常の人物名はわたる・すみれ。属性を常時ゲージ横へ並べず、第3.2節で確認する。属性文字は未登録でも漢字表示できる例外。

### 3.1 新UIの名前・ゲージ配置（2026-11-09整理）

- 確定・本体未実装。名前は比較0.12の②「墨ぼかし」を採用。顔＋名前の過去案や別比較の②と混同しない。
- 敵は顔なし、名前＋細い控えめな朱色系の字力バー＋外周ATB。数値・属性を出さない既存規則を維持し、内部値・弱点・対象選択は変更しない。
- キャラクターの通常位置付近へ自動配置し、戦闘開始時に決めた位置を通常は変えない。味方は2人とも足元、敵は頭上を基本とする。重なる場合は味方2人をまとめて頭上、さらに必要なら左右候補へ。味方の方向をそろえる。
- 人物・他ゲージとの重なり回避と画面内への収まりを優先し、基本の戦闘配置で余白を確保する。具体的な座標・余白量・当たり判定寸法・全編成の最終見た目は検討中。
- 演出上密集が必要な場合だけ、間隔を少し詰める→方向をそろえ横へずらす→その戦闘だけ画面端の専用位置へまとめる。文字・ゲージを小さくせず、入力エリアへはみ出させない。
- 移動・攻撃・帰還中は本人の名前・ゲージ一式を隠し、タップ領域も無効にする。敵味方共通。他の人物の表示は維持し、一時位置へ追従させず帰還後に元位置へ戻す。時間・行動開始処理はBATTLE_DEMO第2.1節。
- 長い敵名は自動縮小・省略せず、意味の切れ目で2行まで。名前全体に墨ぼかしを敷き、名前に合わせて字力バーを伸ばさない。
- 敵名は推奨最大10文字。漢字・かな・英数字・記号・空白を各1文字と数え、1～6文字は原則1行、7～10文字は2行を目安とする。実際の字幅を優先し、10文字超も使用可。幅・改行等は個別調整し、強制制限にしない。

- パネルは下側の手書き／操作エリア側へ置き、人物に重ねず、他のダイアログとも重ねない。複数要求時の詳細な優先順位・待ち行列・強制閉鎖条件は未決定。

## 4. メッセージ・通知・入手

- 会話・物語・調査・入手・操作不可理由はマップ内の共通メッセージ枠。第3.2節の属性確認パネルは、下側へ置く明示的な例外とする。操作エリアに文章を分散させず、問題文・回答結果・時間・ボタン等の操作に必要な情報を置く。
- メッセージ枠は会話と通常通知を重ねない。会話中は必要な通知を既定の順序で扱い、会話を短時間通知で消さない。
- 通常通知は短く自動消去。文章を簡潔に推敲し、表示時間は現設定を基本に実機の問題があるものだけ調整する。通知履歴・新しい確認手順は追加しない。
- 画面やボタンで分かる操作を、説明文で毎回繰り返さない。出題・練習の定型指示はLEARNING 2.1に従い短縮。v0.9.27では初戦／火薬の案内と札・解除の定型文も短縮する。初回に必要な選択先、封印の解除条件、処理エラー時の再試行、保存失敗・上書き確認など判断に必要な情報は残す。物語・手がかりを機械的に削らない。
- 保存成功は短く、保存失敗など重要な問題は理由を読めるよう保持。検索結果なし・詳細の説明など画面の状態文章を自動通知として消さない。
- 初回文字喰い説明は状態変化と解除方法を中心に短縮済み（MAGIC_SEALS）。毎回長い説明・記号の説明を詰め込まない。
- 札・巻物は内容を読んで進める入手表示とし、短い普通通知と分ける。複数札はまとめ、紙が漢字の書へ写る／吸い込まれる演出。札・巻物・記録・魔法完成は見分けられるようにする。
- v0.9.30で札入手時の「なぞりは1字だけ。スキップ可。」を削除する。代表1字の初回なぞり・スキップと同等登録の機能は維持（LEARNING）。
- 入手と確定保存を二重適用せず、会話・入手中は探索入力・追跡を停止。通知を読めたことと、代表字の初回なぞり・登録を区別。
- ダメージは対象付近に最終合計1つ（白系）、回復は緑系で数字のみ、＋を付けない。v0.9.36実装：表示は既定計算後の値を使い、残り字力／回復余地による適用上限で切り詰めない。実際の字力更新は0～有効最大の範囲。満タン近くでも計算回復が正ならその値を表示する。通常回復と封印解除差分が同時にある場合も、既存の各回復効果を上限で削る前の値として扱い、解除自体の計算・演出は維持する。
- 弱点は数字の上にWEAK。計算ダメージ0／使用不可等のMISSは維持。計算回復0は数字なし・回復なしの既定結果。実際の回復余地が0なだけの場合と区別する。
- 数字の残存や短い効果の消滅を、次の行動開始の待ち時間にしない。顔・字力枠・入力欄を長く隠さない。

## 5. 設定とデバッグ

- v0.9.35：音楽／効果音の音量はタップと指のドラッグで連続調整し、100％から下げる・0％から上げる・指を離して端から再操作・範囲外へ動かして戻す操作に対応する。移動中に表示・実音量・保存値を更新し、開き直し／再読込で保持。範囲・初期値・消音・曲と効果音の内容は維持する。
- v0.9.34の端点ドラッグはユーザーから未改善と報告。標準rangeへpointer追跡を付加する方式を終了し、余白を含むDOMスライダーへ変更。指はtouch開始／移動／終了／取消、マウス・ペンはpointer captureで処理し、両経路を二重適用しない。標準つまみやlabelの既定動作へ依存しない。両端のつまみを操作領域内へ収める。音量欄のみtouch-action:noneで、ページ全体のズーム／スクロール抑止は維持する。
- スライダーは音量名・最小／最大／現在値をアクセシビリティ属性で公開し、フォーカス・矢印（1％）・PageUp／Down（10％）・Home／Endに対応。端点は0／100に制限し、次の単指操作では失われた古い追跡を引き継がない。効果音の試聴は値を変えて操作を終えた時に行う。
- 音声の開始・復帰はpointerdownだけに依存せず、touchend・click・keydownでも再開を試す。中断／停止状態ではresumeを試し、再開できた場合に音量と次の演奏時刻を同期する。拒否時に成功扱いせず、次の操作で再試行する。停止処理と再開が重なった場合も、停止完了後に現在のゲーム状態を確認する。非表示／ゲーム停止時は無音を維持し、曲・音符・テンポ・既存ゲインは変更しない。
- 2026-10-24、ユーザーから端末・ゲームの音量を上げマナーモードを解除しても音／BGMが出ない場合があると報告。音そのものの以前の良好評価を撤回するのではなく、断続的な無音を別の報告として管理する。v0.9.35の確認結果は次項のとおり。

- 通常設定は回答中ゲージ進行ON/OFF、デバッグへの入口、漢字の書へ戻る、タイトルへ。音量は音実装時に追加。
- 復活・区画途中開始・戦闘／文字喰い／探索移動の検証調整はデバッグへ。入口にパスワード・長押し等の特別操作を追加しない。
- 調整値は進行セーブと分離、端末・ブラウザごとに保持し初期値へ戻せる。全調整項目の接続を完了扱いにしない。
- 非表示で自動停止、復帰は再開。停止中の入力・押した反応を残さない。常設の手動一時停止メニューは今回追加しない。
