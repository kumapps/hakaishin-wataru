# 戦闘回答UI 和風デザイン復元 テスト版

Mac／PCでZIPを専用フォルダーに展開し、そこで `python3 serve-ipad-preview.py` を実行します。
Mac Safariは `http://localhost:8765/battle-ui-pr4-ipad.html` を開きます。
iPad Safariは同じWi-Fiで `http://配信PCのLAN内IP:8765/battle-ui-pr4-ipad.html` を開き、縦向きで操作します。
終了時は配信側で Ctrl+C を押してください。

タイトルの「戦闘の検証」から「敵1体を試す」を選び、「たたかう」「漢字の書」で回答画面を確認します。
単字・複数字の入力、書き直し、回答、パス、攻撃・回復ボタンの有効・無効、字力ゲージからの属性確認をお試しください。
選択問題が先に出た場合は回答またはパスで進めます。

テスト版は安定版の保存領域から隔離しており、進行と設定は再読み込みで消えます。
AIモデルは同梱していません。従来どおり初回取得または設定からの手動選択が必要です。
