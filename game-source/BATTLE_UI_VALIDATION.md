# 戦闘新UI 開発版の実装・検証

検証日：2026-11-09（Asia/Shanghai）。基準：main `c6015af`（PR #3統合後）。
対象仕様：UI_COMMON v1.11、BATTLE_DEMO v1.6.5、MAGIC_SEALS v1.5、DEC-005。
ゲーム版はv0.9.36のまま。公開・Playable更新・タグ作成は行わない。

## 実装範囲

- 戦闘のみ上下65：35。単字の手書き欄は最大410×410論理px。人物・成功数・時間・途中発動を上段に整理し、書き直すは左上、わからないは左下、回答は小さい藍色の独立面・縦書き。複数字は既存の中央揃え・固定「の」を保持する。
- 顔なしの名前にCSSの墨ぼかしを敷き、字力バーと外周ATBを表示。敵の数値・属性は非表示。7文字以上の敵名は「の」などの区切りを使って2行化する。文字サイズを自動縮小しない。
- 通常位置の投影から初回に配置を決め、味方は足元→2人とも頭上→左右の順で重なりを検査する。敵は頭上を優先。安全な近傍がない時は画面内の余白候補を使う。帰還中の一時位置へ追従しない。
- 移動・技の実行・帰還中は本人のHUDと対象選択領域を無効化。帰還完了後は元位置へ復元。他の人物は表示を維持する。
- 常時属性・旧「◇本来最大」を戦闘HUDから撤去。封印は名前横に単一の「封」、低下した有効最大値のみ赤字。内部の封印・最大字力計算は維持する。
- 待機中・回答中の味方ゲージから下側の属性確認を開く。本人が保持する属性だけを表示し、封印に❌を重ねる。封印なしでも表示可能。最大字力減少の数値説明は置かない。
- パネル内外の次のタップで閉じ、そのタップのpointer/clickを下の操作へ通さない。表示中の封印変化も反映する。
- 属性確認中のATBは既存設定に連動。OFFでは蓄積・未開始行動を止め、開始済みは完遂。回答制限時間は進む。開閉で筆跡・成功数・残り時間を初期化しない。時間切れ・本人死亡・全敵撃破・戦闘終了・本人の行動開始で閉じる。

## 未決定事項と暫定的な実装範囲

- **味方ゲージの人物切替が可能な状態では、従来の人物切替を優先して維持する。その状態からの属性確認は保留。** 切替が不可能な待機中・回答中は属性確認を利用できる。画像だけへの人物切替限定、長押し、別の競合解決仕様は追加していない。
- メッセージ表示中は新たな属性確認を開かない。既存の説明・アプリ停止によるpause中は属性パネルを一時非表示にし、復帰後に同じパネルを戻す。新しいダイアログ待ち行列や詳細な優先順位は作らない。
- 明示された条件以外の自動閉鎖は追加していない。
- 座標・余白・当たり判定は技術上の暫定値。全編成・狭所・長い名前・全複数字問題の最終調整、属性アイコンの最終意匠は保留。墨ぼかしは仕様記述に基づくCSS表現であり、未収録の比較試作原本との画像一致確認ではない。

### 再実行

`game-source/`で`npm ci`、`npm run dev`を実行する。テスト用Playwrightはゲーム依存に追加せず、別の作業領域へ用意する例：

```sh
npm install --prefix /tmp/battle-ui-runner --no-package-lock playwright
PLAYWRIGHT_MODULE=/tmp/battle-ui-runner/node_modules/playwright/index.mjs node tests/battle-ui.mjs
PLAYWRIGHT_MODULE=/tmp/battle-ui-runner/node_modules/playwright/index.mjs node tests/battle-ui-smoke.mjs
```

Chromeの場所は`CHROMIUM_PATH`で指定可能。既定は`/usr/bin/chromium`。テストは`http://localhost:5173`を使用する。smokeの任意スクリーンショットは`BATTLE_SCREENSHOT`で保存先を指定する。
